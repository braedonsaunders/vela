# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private reporting: open the repository's **Security** tab and choose
**Report a vulnerability**, or go to
<https://github.com/braedonsaunders/vela/security/advisories/new>.

Include what you found, how to reproduce it, and which platform and version you
used. We will acknowledge the report, keep you updated while we fix it, and credit
you in the advisory unless you prefer otherwise.

## Scope

This covers the Vela client in this repository: the web/PWA app, the native hosts,
the player, the skin renderer and the release tooling. Problems in Ether itself
belong in the [Ether repository](https://github.com/braedonsaunders/ether).
Problems in a third-party component (FFmpeg, libmpv, libass and others) should
also go to that project.

Security fixes go into the latest release.
